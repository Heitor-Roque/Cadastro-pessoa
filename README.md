# Cadastro-pessoa

Desenvolvi este projeto com objetivo de progressão e treino, para que no futuro eu possa me tornar um bom desenvolvedor.

Projeto introdutório em Java com orientação a objetos. Demonstra a criação de uma classe com atributos (nome, idade e altura), instanciação de objetos e entrada de dados via terminal. 
Introductory Java project using object-oriented programming. Demonstrates class creation with attributes (name, age, and height), object instantiation, and user input via terminal.
